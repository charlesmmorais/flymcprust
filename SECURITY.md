# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(private vulnerability reporting). Do not open a public issue.

Include what you found, how to reproduce it (a failing test is ideal), and
the impact you expect. You will get an acknowledgment, and the fix will be
coordinated with you before any disclosure.

## Supported versions

The project has not had a release yet. Fixes land on `main`.

## Security model

[docs/SECURITY.md](docs/SECURITY.md) describes the threat model, the
controls the SDK applies by default, what applications must do themselves,
and the log of security reviews.
